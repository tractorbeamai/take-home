# Hiring

Interview guides, scorecards, and hiring process documentation for Tractorbeam.

## Structure

- `gem-setup.md` — Gem ATS pipeline structure and candidate-facing details
- `interviews/` — Per-interview prep guides and scorecard definitions
  - `01-phone-screen.md`
  - `02-behavioral.md`
  - `03-take-home.md`
  - `04-technical-screen.md` — Remote, 30 min. Rate limiter coding gate.
  - `05-onsite.md` — In-person, 60 min. Take-home deep dive + systems design.
  - `06-team-lunch.md`
  - `07-client-screen.md` — After onsite, only for candidates we're ready to offer.
- `take-home/` — Exercise repo sent to candidates (zip before sending)
  - `README.md` — Candidate-facing instructions
  - `scripts/` — IAM setup/teardown for per-candidate Bedrock access
  - App source (TanStack Start + Drizzle + shadcn/ui + Bedrock chat)
