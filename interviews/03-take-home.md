# Take-Home Exercise

**Duration:** 2-5 hours (5-day deadline)
**Reviewer:** Wade Fletcher (Co-Founder)
**Delivery:** Email with instructions when candidate enters the Technical stage

## Interview Prep (Gem internal note)

The take-home is a TypeScript/React app with AI features; the same stack and the same kind of problem we work on. Candidates should use AI tools (Claude Code, Cursor, Copilot, etc.). We're evaluating how they think, architect, and ship with the tools we use, not whether they can write boilerplate from memory.

Send the exercise promptly when the candidate reaches this stage. Review the submission before scheduling the technical interview so Wade can reference specifics.

## Exercise Format

**Stack:** TypeScript, React, AI integration (LLM API calls, embeddings, tool use, etc.)

The exercise should:

- Be completable in 2-5 hours by a competent engineer using AI tools
- Have a clear deliverable (working app, deployed or runnable locally)
- Leave room for architectural decisions. Don't over-specify.
- Include a brief written component (README or design doc explaining their choices)

**Candidate instructions should explicitly state:**

- AI tools are encouraged. We want to see how you use them.
- We care more about your decisions than your keystrokes
- Include a README explaining: what you built, decisions you made, what you'd do differently with more time
- Submit via GitHub repo link (public or private with access granted)
